# Qwen Image 2.1 turbo int8 workflow
Qwen Image 2.1 turbo int8 workflow: Text to image and Edit.

qwen_image_2.1_turbo_int8_convrot.safetensors availale on: https://huggingface.co/Comfy-Org/Qwen-Image-2.1/tree/main/diffusion_models

Performance (1024x1024) Text to image: ~4 seconds for a second-generation image on an RTX 5070 Ti; ~8 seconds on an RTX 5060 Ti 16GB.

Performance (1024x1024) Edit: ~7 seconds for a second-generation image on an RTX 5070 Ti; ~14 seconds on an RTX 5060 Ti 16GB.
